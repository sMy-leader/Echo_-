# M1.5 验证记录 — 视觉基础 + 角色 Prefab 接入

日期：2026-10-22
Unity：`6000.4.0f1`
构建后端：Mono2x

## 1. 本块范围

目标：把“逻辑胶囊”和“视觉根节点”拆开，并接入正式角色 Prefab。

已实现：

- `PlayerView` / `GuardView` / `EchoView` 增加 `visualRoot`，根节点统一在脚底；
- `PlayerView` / `GuardView` / `EchoView` 增加可选 `Animator` 字段和参数桥；
- 无 Animator 时使用程序化浮动/倾斜 fallback；
- 守卫增加 `forwardIndicator`，解决胶囊/模型朝向不可读；
- `GuardView.OnDrawGizmosSelected` 画视锥调试线；
- `GameLoop.CreateEchoView` 改为“根节点 + 视觉子节点”，支持 `echoVisualPrefab`；
- `M0SceneBuilder` 接入：
  - `Player_robot.prefab`
  - `Enemy_robot.prefab`
  - `Echo_robot.prefab`（赋给 `GameLoop.echoVisualPrefab`）
- 找不到 Prefab 时回退胶囊，灰盒仍可运行；
- `EchoView` 运行时把 URP Lit 材质切成半透明幽灵材质（Alpha Blend + 青色）。

未实现（后续）：

- Animator Controller / Blend Tree（模型是一体低模，当前用程序化副动画）；
- VFX Graph / ParticleSystem 的悬停、能量核心、消散特效；
- 完整 Mecanim 残影回放（需要扩展 EchoFrame）；
- 模型面数/贴图压缩优化（当前模型约 50k tris，贴图 2048）。

## 5. 资源现状与优化建议

当前 `Assets/Game/Art`：

```text
Art/
├── Animation/   PlayerController / EnemyController（目前为空控制器）
├── Materials/   player_robot / enemy_robot / echo_robot（URP Lit）
├── Model/       Player_view / Enemy_view / echo_view（各 ~50k tris）
├── Prefabs/     Player_robot / Enemy_robot / Echo_robot
├── Textures/    每角色 basic/normal/metallic/rough，2048
├── UI/ VFX/ Videos/（空）
```

建议：

1. 贴图 Max Size 先降到 1024（normal 1024，metallic/rough 512 足够）；
2. 模型目标 20–30k tris；当前 50k 对三个小型机械体偏高；
3. 正式残影做专用 Ghost Shader，而不是运行时改 URP Lit；
4. 悬停/能量核心/消散用 ParticleSystem 或 VFX Graph 挂在 visualRoot 下；
5. YooAsset 等 M2/M3 再接，当前直接 Prefab 引用；
6. Prefab 命名、pivot、材质槽统一，详见 `Docs/ArtPipeline.md`。
